Код проекта «METALL ASIA - единая система управления» на коммите `ec6eb13`
(ветка `feature/frontend-import`, 08.10.2026) - ровно то, что сейчас стоит
на стенде `metall-asia.cloudplus.uz` (версия `ec6eb13-202610081406`).

## Чего в архиве нет и почему

- `node_modules/` - зависимости, ставятся `npm ci` в `backend/` и `frontend/`;
- `.env` и `.env.*` - в них пароли базы и ключ подписи токенов, они лежат
  отдельно от репозитория;
- `dist/`, `dist-qa/` - сборка, делается `npm run build`;
- `qa/*/shots/` - скриншоты прогонов, это артефакты, а не исходники;
- договор и Спецификация - не код, лежат отдельно.

## Как поднять локально

```
cd backend && npm ci && docker compose up -d && ./scripts/db-bootstrap.sh
npx prisma migrate deploy && npm run seed && npm run start
cd ../frontend && npm ci && npm run dev
```

Подробности и переменные окружения - `docs/08-STAND-DEPLOY.md`.
Тесты бэкенда: `cd backend && npx vitest run` (1389 тестов, 95 файлов).
Живые прогоны: `cd qa && bun run <имя>` - перед полным кругом `npm run seed`.
